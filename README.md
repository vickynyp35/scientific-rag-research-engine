# 🔬 Scientific RAG Research Engine

An advanced AI-powered research assistant that allows users to upload multiple scientific research papers and ask questions based on their content.

## 🚀 Features

- 📄 Upload multiple PDF research papers
- 🔍 Hybrid search using FAISS and BM25
- 🤖 AI-powered question answering
- 🎯 Retrieval relevance score
- 📚 Source-based answers with citations
- ⚖️ Compare multiple research papers
- 🔎 Identify agreements, contradictions and research gaps

## 🛠️ Technologies Used

- Python
- Streamlit
- FAISS
- BM25
- Sentence Transformers
- Cross-Encoder Reranking
- Ollama
- PyPDF2
